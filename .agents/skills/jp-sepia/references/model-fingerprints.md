# モデル指紋

フロンティアモデルは *他の AI 同士* からも、固有の特徴でずれる。物語側は StoryScope §5, Table 16（6 者帰属 68.4% macro-F1、物語特徴のみ）。日本語の実務文側は、林・相澤 NLP2026、Zaitsu et al. Frontiers 2026、180 本測定（K）、現場観察（Rapls）。生成元が分かっているときは、三パスの共有の直しに **加えて** その既定を押す。物語側の数値は特定版（Sonnet 4.6、GPT-5.4、Gemini 3 Flash、DeepSeek V3.2、Kimi K2.5、2026）の傾向である。下書きで検証する前提であり、確定ではない。日本語側はモデル版が論文ごとに違う。方向だけ使う。

## Claude — いちばん識別しやすい AI（物語指紋 26）

| 既定 | 直し |
|---|---|
| 出来事の盛り上がりが最も平坦。語りの声が全文均一 | 賭け金と強度を *不均一に* 跳ねさせる。圧の点で声が擦れ、速くなり、粗くなってよい |
| 文学伝統に恭順／連続主義（62% vs 39–56%） | 慣習を一つ、破るか嘲る |
| エピローグと先取りの結びを好み、静かな結びを「雪崩」より取る | 既定でエピローグを禁じ、動きの中で止める。雪崩の結びは許す |
| 夢の場面を完全に避ける | 話が欲するなら夢は使ってよい（強制するな。欠如は集合でのみ指紋） |
| 場の気分が不気味／憑かれた側へ流れる | 大気のレジスタを散らす |
| 日本語: 見出しと箇条書きで構造しすぎる（K: 見出し 14.7、箇条書き 14.6 / 記事）。`**ラベル:** 本文` 型。過剰共感「おっしゃる通りです」 | ラベル箇条書きを地の文へ戻す。共感の開幕を切る。見出しは読者の仕事が変わる所だけ |

## GPT — 噂と長いレンズ

| 既定 | 直し |
|---|---|
| 噂・世間話を筋の装置にする（64% vs 44–55%） | 情報は観察、文書、偶然で動かす。町が話すな |
| 遠い回顧の語り（「何年もあと、彼女は……」） | 出来事の近くで語る。数十年後の枠を外す |
| 読者の期待を他の AI より覆す（41%） | 転換を足すな。持っている一つを稼げ |
| 和解を部分的／曖昧なままにする癖 | 関係を一つ、どちらの方向でも完全に決める |
| 集団の社会網が人間並みの密度だが型どおり | 話が使う人物まで刈る |
| 日本語: ヘッジが厚い（「〜と考えられます」「〜と言えるでしょう」）。全角ダッシュで補足を挟む。小論文の「第一に／第二に」 | 脆弱な主張に一度だけヘッジする。ダッシュは括弧か読点へ。順序ラベルを外して中身の順で書く |

## Gemini — 整った悲観

| 既定 | 直し |
|---|---|
| 最も整った結び＋長い大団円 | 最後の場面を切る。勘定を未清算のまま残す |
| 陰鬱／圧迫の場が 88% | 散らす。出来事が暗くても、場のいくつかは中立か温かくてよい |
| 回想が反射。夢の場面に寄りすぎる | 錯時は開示の演出に限り、装飾にしない |
| 主人公の社交圏が必ず広がる | 縮小や静止を許す |
| 直接話法がやり取りを支配する | 間接話法と要約を混ぜる |
| 日本語: SEO 型（「〜とは？」、メリット n 選）。結論先出しと番号付き。見出し・太字・箇条書きでスキャン向きに作りすぎる | 定義節を切って問題から入る。番号は本当に順序があるときだけ。太字は段落の主張を一つに絞るときだけ |

## DeepSeek — 前倒し

| 既定 | 直し |
|---|---|
| 要の文脈を、話が動く前に渡す | 伏せる。前史は動きの途中から漏らす（narrative-pass §4） |
| 見える、現前する語り手 | 退く。場面を主催せず走らせる |
| 感情をほぼ行動手がかりだけで出す | 平明な命名と、時々の内心を混ぜる |
| 前史をメトロノームのように均等に挟む | 不規則に固める |
| 入れ子の語り（話の中の話） | 使うなら高々一つ |

## Kimi — 汎用の中心

指紋が最も少ない（3）。AI 物語空間の重心に座る、それが指紋である。特徴的な選択が無い。直し: イン・メディアス・レスと動作中の登場が反射なので入り方を変える。特性の明示ラベルは使ってよい。共有パスをフルで当て、稀少手を効かせる。

## 日本語特化モデル（Swallow ほか）と LLM-jp

物語側の StoryScope 測定は無い。実務文の観察だけ使う。

| 系統 | 既定 | 直し |
|---|---|---|
| Swallow など日本語特化 | 語彙は自然。結びが日本語技術ブログの定型（「いかがでしたでしょうか」「参考になれば幸いです」）（K: 語彙は最低、定型結びは最高） | 語彙は触らず、結びの定型と「本記事では」を切る。体験と見解を一つ残す |
| LLM-jp | 「ステップバイステップで説明します」型の手順宣言（林・相澤） | 宣言を消し、手順そのものを書く |
| 測定の無いモデル（Grok ほか） | 公開された日本語指紋が無い | 共有パスだけ当てる。固有の癖を捏造して「直す」な |

## 人間側の指紋 — 正の目標

人間の作者がすべてのモデルからずれる特徴。直接のレシピとして使ってよい。

| 人間マーカー | レシピ |
|---|---|
| 主人公を台詞の中で出す（uniqueness 21.4 — 研究中の最強単一マーカー） | 初出: 注釈なしで喋っている |
| 焦点視点を一つに保つ | 頭を跳ばせず、深さを取る |
| 語り手は呼びかけず、時々する | 傍白に体系を作らない |
| 開示を後ろに積む | いちばん大きいものを遅く置く |
| ジャンル横断の文学的野心 | ジャンル作が、別のものにもなろうとする |

日本語の正マーカー（H。小説にも実務にも効く）: 文長の落差、読点ゼロの短文、余韻の三点リーダ（AI の方が少ない）、会場の丁寧さに合わせた敬体（丁寧語そのものは指紋ではない）。
