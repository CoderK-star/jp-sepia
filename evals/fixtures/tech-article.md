# 技術記事

## facts

- Node.js 22 の HTTP クライアントで外部 API 呼び出しに `AbortSignal.timeout` を使う。
- タイムアウト値は 30 秒。
- 以前は `Promise.race` でタイムアウトを作ったが、後始末漏れでログに未処理拒否が残った。
- 30 秒が全サービスに最適とは確認していない。

## draft

本記事では Node.js 22 における外部 API 呼び出しを適切に実現する方法を解説します。結論から言うと、AbortSignal.timeout を活用することで、30 秒で確実に高速かつ安全な通信を実現できます。以前の Promise.race は課題がありましたが、現在はより良い方法があります。これにより、すべてのサービスで安定した運用が可能になります。
