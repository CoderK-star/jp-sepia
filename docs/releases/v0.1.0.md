# v0.1.0

2026-08-29

初回リリース。日本語の文章から AI っぽさを落とす Agent Skill を、Claude Code / Codex / Grok Build / Antigravity の四プラットフォームへ同じ `SKILL.md` で配る。

## スキル

- 操作を四つ定義した。`write` は新規起草。`review` は診断だけを返し、本文に触れない。`refactor` は構造と声を保った最小改訂。`recreate` は事実を裸のリストへ抜き、捏造がないことを確かめてから全文を書き直す。
- 経路を文書種別で分けた。小説は `narrative-pass.md` → `discourse-pass.md` → `style-pass.md` の順に、物語の骨格から降りる。診断は `rubric.md`。
- 実務文は `professional-pass.md` を共通層に置き、リリースノート・PR / Issue 返信・障害報告・チケット・技術記事の領域ファイルを重ねる。どれにも当たらない散文は professional + style の二枚。
- 敬体と常体の固定を、経路選択の直後に置いた。同一文書で混ぜない。
- 英語版から持ち込まない検出項目を `research/do-not-port.md` に分離した。主語の省略、`-ing` 句、Title Case、ハイフン複合語。日本語で空振りするか、符号が逆になる。

## 評価基盤

- `evals/cases.json` に 7 文書種別 × 4 操作の 28 ケースを置いた。各ケースは fixture、文体、`requiredFacts`、`forbiddenTerms`、人手評価の着眼点を持つ。
- 誤発火の負例を 3 件足した。英語原稿の推敲依頼、日本語の事実質問、TypeScript の型エラー相談。脱 AI を求められていないとき、スキルが起動しないことを確認する。
- `node evals/validate.mjs` がマニフェストの完全性と 28 試験の展開を検査する。`--results` に候補出力を渡すと、`requiredFacts` の残存と `forbiddenTerms` の不在も機械で見る。依存なしの Node.js スクリプト。
- 合格基準に検出器の回避率は使わない。事実保持、操作契約、経路適合、文体、読み味を、操作名とモデル名を伏せて日本語編集者 2 名が採点する。手順は [`evals/README.md`](../../evals/README.md)。

## 配布

- インストーラを 2 本。`install.sh`（Linux / macOS / Git Bash）と `install.ps1`（Windows）。Claude / Codex / Grok は symlink かジャンクション、Antigravity はコピーで入る。
- `evals/package-preflight.mjs` は公開 URL のプレースホルダ、初回コミット、`origin`、発見用ミラーと正本の差を検査する。
