# Pass 1 — 物語の骨格

七つの決定グループに、日本語小説向けの第八グループを足す。各項目は人間と AI の差、生成時、改訂時を持つ。数値は StoryScope（S。英語短編 61,608 篇）、Beguš 2024（B）、Xu et al. PNAS 2025（X）、Nonaka & Perry 2025（N）、QUDsim（Q）。百分率は *人間 vs AI*。StoryScope は英語コーパスなので、数値は事前の目安であり日本語の実測ではない。方向は言語をまたいで残る（テーマの説明過多、単線の因果、身体感覚だけの感情、余韻のない学びの結び）。

設計表は全部埋める。実行するのは **3–5 手と稀少手 1 つ**（SKILL.md の較正）。⚑ は既存 humanizer がほぼ触らない層。

## 設計表

起草前（Workflow A）か、診断の要約（Workflow B）で埋める。

| 決定 | この話での選択 | 狙う帯 |
|---|---|---|
| テーマの扱い | 明示 / 含意 / 伏せる | 含意が既定 |
| 副線 | なし / 平行 / 対比 / 独立 | ある話はおよそ 4 割 |
| 決着の駆動 | 主人公の選択 / 混合 / 外部 | 混合か外部がおよそ半分 |
| 結びの型 | 外的行為 / 内的受容 / 部分 / 開いたまま / 破局 | 内的受容を既定にしない |
| 時間 | 直線 / 中程度の錯時 / 編み込み | 中程度（1–5 で 2–3） |
| 開示の速度 | 前倒し / 均等 / 後ろ倒し | 後ろ倒し |
| 感情の出し方 | ラベル / 行動 / 身体 / 曖昧 の混合 | 行動主導。身体はピークだけ |
| 主人公の登場 | 外形描写 / 動作中 / 台詞中 / 思考 / 他者の報告 | 台詞中か動作中 |
| 主人公への道徳的立場 | 肯定 / 悲劇的欠陥 / 両義 / 反英雄 | 両義がおよそ 6 割 |
| 現実世界の錨 | 実在する作品・場所・商標 | 明示の固有名を 1 つ以上 |
| 人間関係の形 | 出会わない組、嫌っている組 | 疎、感情の合計は中立付近 |
| 視点 | 一人称 / 三人称限定 / 神視点 | 一つに固定。無自覚な神視点を避ける |
| 地の文の文体 | 常体 / 敬体 | 一つに固定。台詞の役割語とは別勘定 |
| 稀少手 | この前提では珍しい構造上の選択を一つ | ちょうど一つ |

## 1 ⚑ テーマを説明しない

| 特徴 | 人間 | AI |
|---|---|---|
| 語り手がテーマを明示する（S） | 52% | 77% |
| テーマの明示度 1–5（S） | 3.28 | 3.94 |
| 対話が哲学討論になる（S） | 34% | 59% |
| 道徳・哲学の比重 1–5（S） | 3.26 | 3.68 |
| テーマの統一度 1–5（S） | 4.41 | 4.74 |

**生成:** テーマは決めて、出来事に預ける。語り手は教訓を要約しない。喪の弧は「彼女が学んだこと」で終わらない。対話は欲求と関係の仕事をする。家賃の話であり、悲嘆の本質の話ではない。テーマに奉仕しない場面を一つ残す（人間の統一度は 4.4/5 であって 5/5 ではない）。

**改訂:** 末尾三段落、および「人とはそういうものだ」「そのとき彼女は悟った」「結局、大切だったのは」を探す。切るか、具体の行為か像に替える。観念で争う対話は、登場人物が欲しい具体物の争いへ戻す。象徴の解説文は消し、象徴だけ残す。

> 説教する最終行は最も安定した AI の結びである（B: "love knows no boundaries" が定型）。止まる結びは人間、結論する結びは機械。日本語では「彼女は、愛とは諦めないことだと知った」が同じ位置を占める。

## 2 ⚑ 単線を緩める

| 特徴 | 人間 | AI |
|---|---|---|
| 副線が一つもない（S） | 57% | 79% |
| 副線が主線のテーマに平行（S） | 42% | 21% |
| 因果の連続度 1–5（S） | 3.92 | 4.20 |
| 再生成で同じ要素が残る drop ratio（X） | 3.7% | 9–11% |

**生成:** およそ五話に二話は副線を持つ。持つなら、主テーマを言い直すのではなく斜めに響かせる。因果を一度切る。発端から来ない挿話、舞台裏から届く結果。不発の伏線を一つ植える。全部回収する帳簿は機械の仕事である。

**改訂:** 下書きをビートの列にする。直前のビートだけが次を起こしているなら、因果を一つ舞台裏へ移すか、起源の違う出来事を差し込む。長さが副線を持てるのに無いなら、一本編む。

**エコー試験（X）:** 転換ごとに問う。*この前提を二十回再生成したら、同じ転換がまた出るか。* 助けてくれる見知らぬ人、きれいに解ける問題、予定どおりの和解。これらは再出する。この話の個別事情が要る転換に替える。カフカの警官は「やめとけ」と言って去る。二十回の再生成は二十人の親切な案内係を出す。

## 3 決着と結び

| 特徴 | 人間 | AI |
|---|---|---|
| 決着が主人公自身の選択（S） | 46% | 69% |
| 内的理解・受容で決着（S） | 27% | 47% |
| 道徳的に両義の主人公（S） | 59% | 38% |

**生成:** 成長した主人公が選び、受容し、納得する三重既定を既定にするな。半分は偶然、他人、制度が決める。部分的、開いたまま、破局でよい。最後の道徳的位置は混ざっていてよい。事件では正しく、行為では間違っている。

**改訂:** 下書きが「決める＋受け入れる＋理解する」で終わるなら、三脚の一本を折る。勘定を全部清算する後日譚を切る。完結したと感じる一点の、一つ手前で止めるのが通例の直しである。

日本語の余韻はここに属する。余韻は情報を伏せることであり、テーマを詩的に言い直すことではない。「……彼女は、それでも歩いた」で主題を回収するのも機械である。

## 4 ⚑ 直線は選択であり既定ではない

| 特徴 | 人間 | AI |
|---|---|---|
| 時間の不連続 1–5（S） | 2.40 | 2.12 |
| 錯時（回想・先取り）の強度 1–5（S） | 2.58 | 2.31 |
| 非線形で開示を遅らせる 1–5（S） | 1.96 | 1.68 |
| 驚きのあと前文を染め直す深さ 1–5（S） | 3.28 | 2.95 |
| 開示の速度（人間側の指紋、S） | 後ろ倒し | 均等 / 前倒し |

**生成:** 人間の帯は *中程度* の非線形である。葬式から入って数十年を巻き戻す話であり、パズル箱ではない。時間の跳びは **情報の演出** に使う。原因を持ち、結果から開く。最大の開示は後ろへ置く。

**改訂:** 原因から結果へ順に語っているなら、伏せた方が効く場面を後ろへ移す。DeepSeek 型の前置き（動き出す前に文脈を全部渡す）を切る。文脈は動きの途中から漏らせ。

## 5 ⚑ 感情と感覚: show-don't-tell を教条にしない

| 特徴 | 人間 | AI |
|---|---|---|
| 感情が主に身体感覚・隠喩（S） | 38% | 81% |
| 感情が主に明示ラベル（S） | 29% | 8% |
| 嗅覚が支配感覚に入る（S） | 57% | 82% |
| 環境が内心の鏡 1–5（S） | 3.58 | 4.07 |
| 感覚密度 1–5（S） | 3.66 | 3.93 |
| 内心へのアクセスの深さ 1–5（S） | 3.67 | 3.93 |

**生成:** AI は「見せろ、語るな」を教条として実行する。恐れは必ず胸の締めつけ、冷や汗、灯りの衰え。人間は四モードを混ぜ、いちばん地味な二つに寄る。行動が先、平明な命名が次（「怖かった」は人間の文であり、モデルはほぼ書かない）。身体化は話あたり一、二のピークに残す。天気は天気でよい。嵐が毎回結婚を運ぶ必要はない。嗅覚は機械散文の通人の感覚になっているので配給する。

日本語の対応物: 「胸がざわついた」「喉がからからになった」「雨が彼女の気持ちを洗い流した」。桜、夕暮れ、雨音を心情の字幕にしない。擬音は人間がよく使うが、ドキドキ／ズキンの在庫回転は機械である。一つ、その場でしか出ない音を置け。

**改訂:** 感情ビートをモード分類する。身体が支配しているなら、大半を行動か平明な命名へ戻し、強い一、二だけ身体に残す。環境が場ごとに気分を影にする箇所を剥がす。三感覚の文は第三感覚を切る。

## 6 ⚑ 人物と関係の網

| 特徴 | 人間 | AI |
|---|---|---|
| 主人公を外形描写で紹介（S） | 30% | 52% |
| 人間側の指紋: 台詞の中で登場（S） | 最強の単一マーカー | 稀 |
| 関係網の密度（N） | 0.18 | 0.34–0.47 |
| 関係の平均感情（N） | −0.06（中立） | +0.24〜+0.66（全正） |
| 敵対関係のクラスタ（N） | 0.395 | 0.07–0.21 |
| 危機の前に投資する 1–5（S） | 2.76 | 2.99 |

**生成:** 主人公は喋っているか動いている状態で出す。「犬は火曜日に来た」が、容姿と経歴の一段落に勝つ。関係図は疎。出会わない組、第三者経由だけの組を残す。感情の合計は中立付近。筋と無関係な嫌悪があってよい。敵対は構造を持つ。敵にも味方、内紛、独自の網がある。読者がほとんど知らない人物を危険に晒してよい。

**改訂:** 符号付きの辺で関係図を描く。全員が全員と繋がるなら辺を消す。全部温かいならいくつか冷やす。敵が孤立しているなら、主人公を経由しない関係を一つ足す。

## 7 ⚑ 外側の世界と読者

| 特徴 | 人間 | AI |
|---|---|---|
| 実在のテキスト・作者を明示（S） | 47% | 24% |
| 明示と暗示の混合（S） | 37% | 16% |
| 第四の壁の透過が一度でも（S） | 67% | 39% |
| 読者への直接呼びかけ（S） | 28% | 7% |
| 意味のある場所の数（S） | 1.34 | 1.08 |
| 対話と地の文の比 1–5（S） | 2.95 | 2.70 |

**生成:** 実在するものを名指す。本棚の実在の小説、実在のバンド、具体の国道（SKILL.md の正確性ルール: 実在し正しい参照だけ。材料が無ければユーザーに聞く）。名指しと無名の残響を混ぜる。読者の存在を認める傍白は人間の手である。*時々*。傍白を一、二。メタ枠にはしない。前提が閉じ込めを要求しないなら、場所を一、二足す。対話の床面積を地の文より少し広くする。

**改訂:** 「有名な詩人」「古い歌」とだけあるなら、一つを実在の固有名にする。五千字が一部屋で、閉じ込めが前提でないなら、場面を一つ移す。曖昧な言及ばかりは機械の慎重さである。

## 8 日本語の層（StoryScope 外。方向だけの目安として扱う）

数値は無い。方向だけ使う。選ぶ手数の枠に含めてよい。

| 項目 | 機械の既定 | 人間側へ寄せる手 |
|---|---|---|
| 視点 | 三人称のはずが、他者の内心を説明し、神視点になる | 一人称か三人称限定か、先に決めて守る。他者の内心は表情・台詞・誤読で出す |
| 役割語 | 俺／僕の混線、わよ／かしら／であるの在庫、年齢・階層と不一致 | 人物ごとに一人称と文末を固定し、崩すなら理由を持つ。地の文の常体／敬体とは別勘定 |
| 説明会話 | 「ご存知の通り、この町では……」 | 知っている側は省略する。読者へ届ける情報は地の文か、知らない側の問いへ載せる |
| 名前 | ハルト、シオン、アヤ、ユイ、蓮、結衣、太郎、花子 | 地域・世代・階層から取る。同じ人物を、呼ぶ側によって違う名で呼ぶ |
| 間 | 沈黙を地の文で説明する | 沈黙は空白と行為で置く。なぜ黙ったかは書かないことが多い |
| 会話記号 | カギの外で心情を同時通訳する | 「」内は声。心内は地の文か、鉤なし。同時通訳を毎行しない |

## 稀少手

人間の話は構造的に *稀* である（rarity percentile 0.71 vs 0.49。五モデルは物語空間の一領域に固まり、人間は散る）。上の帯への較正に加え、この前提では珍しい構造上の選択を **ちょうど一つ** 入れる。語りの距離、ジャンルが滅多に使わない決着、枠がジャンルを塗り替える、など。一つ。二つ以上は演技に読める。
