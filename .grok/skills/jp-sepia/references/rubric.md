# 診断ルーブリック — 中核 30 特徴

人間と AI の小説を最も安定して分ける 30 の物語特徴（StoryScope Tables 13–15。採点基準は公開 taxonomy に合わせた）。これだけで 84.8% macro-F1 — このチェックリストが検出器であり、逆向きに走らせる。数値は英語短編の人間平均である。日本語小説では **方向** を使い、絶対値の一点差で切らない。日本語層（視点、役割語、説明会話）は Group J で別勘定し、ドリフト比率には入れない。

## 手順

1. **グループ単位** で採点する。五回に分ける。一度に全体を見ると、モデルは目立つ一、二軸に潰れ、残りが見えなくなる（slop taxonomy で測定。全文ガイド同時提示時の span precision 0.13）。
2. 各特徴について、点数を正当化する短い箇所を引用する。引用が無ければ点は無い。
3. 下の採点規則を機械的に適用する。ドリフトかどうかの裁量判断をしない。
4. 尺度は注記が無い限り 1–5。「Target」は人間平均。

## 採点規則

| 場合 | 規則 |
|---|---|
| 数値行（尺度／順序） | Target と AI の中点より AI 側に乗ったら **ドリフト**。例: テーマ明示 Target 3.3 / AI 3.9 → 中点 3.6 → 4 はドリフト、3.5 は違う。日本語では中点の 0.3 内側は「観察」に留め、明確な AI 側だけドリフトにする。 |
| 百分率行（カテゴリ／二値） | 話が AI 列の選択肢を示し、かつ AI% ÷ Target% ≥ 1.4 なら **ドリフト**（A–C と E の百分率行はすべて該当。*副線* は累積証拠のみで単独では数えない）。人間側の選択肢が無いこと自体はドリフトではない。 |
| Group D | 人間側の正マーカーを **一つの単位** として扱う。三つとも話のどこにも無いときだけ +1 ドリフト。それ以外は 0。 |
| 該当なし | 機会が無い特徴（危機が無い → 事前投資、開示が無い → 再文脈化）は **n/a** とし、評価母数から外す。参照の明示は、暗示の身振りが一つも無いときだけ n/a。無名の借用引用や、分かる無断の語り直しは機会である。短いテキストは n/a が増える。欠陥ではない。 |
| 過修正 | 数値点が AI 方向から遠く離れた極（不連続 5/5、テーマ明示 1/5）は **過修正の助言**。報告するがドリフト比率には入れない。 |

**振り分け:** 評価可能 = 最大 26 単位 — 採点行 25（A, B, C, E から助言行 *副線* と *場所の多様性* を除く）+ Group D の 1 — から n/a を引く。ドリフト比率 = ドリフト ÷ 評価可能:

| ドリフト比率 | 処置 |
|---|---|
| ≥ 20% | 構造改訂（Workflow B、三パス全部） |
| 10–20% | ドリフトした特徴への局所直し |
| < 10% | style-pass のみ |

## Group A — テーマの過決定（AI は高い側へ）

| 特徴 | 見方 | Target | AI |
|---|---|---|---|
| テーマの明示 | 1 = 含意のまま。5 = 論文の命題のように出来事の解釈を教える | ~3.3 | 3.9 |
| 道徳・哲学の比重 | 倫理討論とテーマ解説が話の快楽を圧するか。語り手の論評とクライマックスの演説を見る | ~3.3 | 3.7 |
| テーマの統一 | 5 = すべての場面・副線・像が一つの核を補強する | ~4.4 | 4.7 |
| 語り手のテーマ論評 | 語りが出来事の意味を一般化するか（「人とはそういうものだ」） | yes ~52% | 77% |
| 対話が哲学討論 | 要の対話が欲求／衝突ではなく観念を論じるか | 支配的 ~34% | 59% |
| 参照の明示 | 無名の曖昧な言及が支配的（人間側は明示と暗示の混合、37% vs 16%） | 暗示のみ ~50% | 72% |

## Group B — 感覚と身体化の演技（AI は高い側へ）

| 特徴 | 見方 | Target | AI |
|---|---|---|---|
| 支配的な感情モード | 強い情動の場面: 明示ラベル / 身体感覚 / 行動 / 曖昧。身体が支配したらドリフト | 身体支配 ~38% | 81% |
| 環境が心理の鏡 | 天候／風景／建築が内心を一貫して外在化するか | ~3.6 | 4.1 |
| 環境の強調 | 背景を超える風景と生態 | ~2.8 | 3.2 |
| 嗅覚イメージ | 定期的に使う感覚に匂いが入るか。分量に対する目立りで判断（掌編なら目立つ一回、長編なら反復） | ~57% | 82% |
| 感覚密度 | 多感覚描写が本文に占める割合。5 = 繁茂し、速度を落とす | ~3.7 | 3.9 |
| 内心アクセスの深さ | 1 = 外側のみ。5 = 意識の流れ | ~3.7 | 3.9 |

## Group C — 構造の流線化（AI は高い／整った側へ）

| 特徴 | 見方 | Target | AI |
|---|---|---|---|
| 因果の連続 | 5 = すべての出来事が発端から結びまで一本で繋がる | ~3.9 | 4.2 |
| 副線 *（助言 — 累積証拠のみ）* | 副線が無い。人間話でも 57% と多いので単独では数えない | 副線なし ~57% | 79% |
| 決着の主体 | 転換点が主人公の選択か、偶然／他者か | 選択 ~46% | 69% |
| 決着の型 | 外的行為 / 内的受容 / 部分 / 開いたまま / 破局。内的受容でドリフト | 内的 ~27% | 47% |
| 主人公の紹介 | 実質的な初出の装置 — 外形描写 / 動作中 / 台詞中 / 内心 / 他者の報告。ドリフトは外形描写のみ。他の四つはドリフトにならない（台詞中が最強の人間マーカー） | 描写 ~30% | 52% |
| 開幕の空間グラウンド | 最初の場面が局所＋広域の場所をどれだけ固定するか（1–4） | ~2.1 | 2.3 |
| 空間の粒度 | 地名、部屋、経路の密度（1–4） | ~2.3 | 2.5 |
| 危機前の投資 | 危機の前に内心／前史を積むか | ~2.8 | 3.0 |

## Group D — 人間側の正マーカー（一つの単位: 三つとも欠けるときだけ +1）

| マーカー | 見方 | 人間 | AI |
|---|---|---|---|
| 名指しの間テクスト | 実在のテキスト／作者／作品を明示 | ~47% | 24% |
| 第四の壁 | 目配せ、傍白、読者の承認がどこかにある | ~67% | 39% |
| 読者への直接呼びかけ | 「あなた」や、読者に向けた一瞬 | ~28% | 7% |

## Group E — 時間の複雑さと多様性（AI は低い／整った側へ）

| 特徴 | 見方 | Target | AI |
|---|---|---|---|
| 時間の不連続 | 時間跳びの頻度と鋭さ | ~2.4 | 2.1 |
| 錯時の強度 | 場面単位の回想／先取りが構造になっているか | ~2.6 | 2.3 |
| 非線形で開示を遅らせる | 時間装置が開示の演出になっているか | ~2.0 | 1.7 |
| 驚きのあと前文を染め直す | 開示が前文をどれだけ塗り替えるか | ~3.3 | 3.0 |
| 場所の多様性 *（助言 — 数えない）* | 3,000 字超が、閉じ込めを前提とせず一つの場所から出ないとき旗 | 場面として完結する場所が 2+ | 単一場所バイアス |
| 対話の割合 | 引用された発話が本文に占める割合（1 = なし、3 = 均衡、5 = 支配） | ~3.0 | 2.7 |
| 主人公への道徳極性 | 話の最終的な立場。明確な肯定か明確な断罪でドリフト | 両義 ~59% | 明確 62% |

## Group J — 日本語層（助言。ドリフト比率に入れない）

引用証拠つきで報告する。処置の優先は本文のドリフト比率に従い、ここは加算の材料にする。

| 項目 | ドリフトと見るとき |
|---|---|
| 視点 | 一人称／三人称限定を宣言しているのに、他者の内心を地の文が説明する |
| 役割語 | 同一人物の一人称か文末が、理由なく場面をまたいで変わる |
| 説明会話 | 「ご存知の通り」型で、読者のための設定を台詞に積む |
| 名前 | ハルト／シオン／アヤ／ユイ／蓮／結衣、または太郎／花子が、世界の根拠なく並ぶ |
| 間 | 沈黙の理由を地の文が毎回通訳する |
| 文体混在 | 地の文で敬体と常体が混ざる（台詞は別勘定） |

## 報告の型

既定は各グループのドリフト要約、引用証拠、処置の一行だけを返す。完全な採点表、`Plan` の手順、`n/a` の内訳は詳細要求時に限る。

段落番号ではなく、短い句を引用する。

```text
JP-SEPIA DIAGNOSIS — <題>
Group A: ドリフト 3, n/a 1（語り手の論評 — 「そのとき彼女は……」; …）
Group B: ドリフト 2（…）
Group C: ドリフト 1, n/a 1（…）
Group D: 0（名指しの間テクストあり — 「…」）
Group E: ドリフト 2（…）
Group J: 視点 / 説明会話（助言）
Advisories: 過修正なし; 副線なし; 単一場所
Drift share: 8 / 24 評価可能 = 33% → 構造改訂
Plan: <深い層から順、引用箇所に紐づく直し>
```
